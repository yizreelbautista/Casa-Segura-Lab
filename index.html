      Configurar mi viviendaHabitaciones y dispositivos editables

      La vivienda incluida al iniciar Casa Segura es una configuración normal y totalmente editable.

      Puedes agregar, renombrar o eliminar habitaciones, puertas, ventanas, cámaras y sensores.

      Cada dispositivo puede cambiar de habitación y de ubicación visual. Los accesos aparecen automáticamente en Estado de sensores.

      Activar o desactivar protecciónUso del PIN y estado de accesos

      En Panel escribe tu PIN y presiona “Activar protección”. Si existe una puerta o ventana abierta, Casa Segura indicará qué accesos debes revisar.

      Para desactivar, vuelve a introducir el PIN y usa el mismo control.

      Botón de pánico y emergenciaQué ocurre después de activarlo

      El botón rojo permanece disponible durante toda la sesión. Al activarlo, la alarma comienza y aparece una pantalla crítica.

      La alarma no se puede silenciar desde esa pantalla sin introducir un PIN válido.

      El sistema simula el envío de una alerta al centro de vigilancia y registra la emergencia en el historial.

      CámarasCámara del dispositivo, LAN/IP y acceso remoto

      La opción “Cámara del dispositivo” usa getUserMedia y solamente se inicia cuando tú presionas Iniciar cámara. En un teléfono puede usar la cámara frontal o trasera porque ambas pertenecen al mismo dispositivo.

      Las cámaras IP pueden estar conectadas por Wi‑Fi o Ethernet dentro de la red de casa. Para acceder desde universidad, trabajo u otra red se necesita una ruta remota segura: plataforma del fabricante, gateway en casa o backend compatible.

      PIN y privacidadMostrar, ocultar y cambiar credencial

      Los campos de PIN se muestran ocultos por defecto. El botón con el icono de ojo permite mostrar u ocultar temporalmente el valor.

      El PIN puede cambiarse desde Configuración. Esta versión académica lo almacena de forma local; una versión de producción debe usar backend, hash y sesiones seguras.

      Base de datosPostgreSQL y operación offline

      PostgreSQL es la base central cuando Casa Segura está online. Varias laptops pueden consultar y sincronizar los mismos registros mediante la API.

      Cuando no hay conexión, Casa Segura conserva una caché local para continuar operando. Al recuperar el servidor, sincroniza las operaciones pendientes.

      El menú “Base de datos” permite inspeccionar viviendas, habitaciones, dispositivos, eventos y notificaciones.

      PostgreSQL y seis laptopsCómo comparten los mismos registros

      Una PC de Casa Segura ejecuta PostgreSQL y la API incluida en la carpeta backend. Esa PC debe tener una IP accesible desde las demás laptops.

      Las laptops nunca se conectan directamente a PostgreSQL. El navegador se comunica con la API HTTP, y la API realiza las consultas SQL.

      IndexedDB continúa funcionando en cada laptop como almacenamiento local. Cuando la API está disponible, las operaciones pendientes se sincronizan con PostgreSQL.

      Para Internet público se requiere HTTPS, autenticación real y una ruta segura hacia el servidor. No expongas el puerto de PostgreSQL directamente a Internet.

      Modo local, LAN e InternetQué ocurre cuando activas Online

      Local: Casa Segura funciona con su base IndexedDB y no necesita Internet.

      LAN: si la computadora y una cámara IP están en el mismo router, pueden comunicarse dentro de la red local aunque no exista salida a Internet.

      Online/remoto: permite que una instalación de Casa Segura se comunique con servicios externos. Para ver una cámara desde otra ciudad no basta con activar un interruptor: la cámara necesita un gateway, nube del fabricante o servicio remoto accesible.

      Casa Segura nunca necesita pedir la contraseña Wi‑Fi; esa conexión la gestiona Windows, Android, iOS u otro sistema operativo.

      Estados visualesQué significan los colores

      Azul: acción normal. Verde: estado correcto. Ámbar: advertencia. Rojo: emergencia o acción crítica.

      La aplicación no depende únicamente del color: cada estado crítico incluye texto descriptivo.
